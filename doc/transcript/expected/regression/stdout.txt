svg-editor 0.1 — type 'help' for commands
Document:
  init [w] [h]                                     create an empty canvas (default 800x600)
  read <file.svg>                                  read an SVG file as the current document
  save [file.svg]                                  save the current document (default: the path it was read from)
  canvas [w] [h]                                   show the canvas size, or change it
Shape editing:
  create <type> <id> [params…] [in <containerId>]  create a shape, at the root or inside a container
  delete <id>                                      delete a shape (a container with all its descendants)
  move <id> <dx> <dy>                              translate a shape by (dx, dy)
  scale <id> <factor>                              scale all geometry of a shape by factor
  set <id> <attr> <value>                          set fill, stroke, stroke-width, a geometry attribute or the text
  group <newGid> <id1> <id2>…                      make a new container holding the given shapes
  ungroup <gid>                                    dissolve a container; its children take its place
  addto <gid> <id>                                 move a shape into a container, as its last child
  front <id>                                       bring a shape to the front of its siblings
  back <id>                                        send a shape to the back of its siblings
Display:
  tree [id]                                        show the structure tree (of the document, or of one shape)
  show <id>                                        show all attributes of one shape
  help                                             list all commands and their syntax
Undo / redo:
  undo                                             undo the latest edit command
  redo                                             redo the latest undone edit command
