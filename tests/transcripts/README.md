## 格式

- 以 `svg> ` 开头的行是**一行输入**：去掉这 5 个字符后的内容原样交给 `Editor.executeLine`。
- 其后直到下一个 `svg> ` 行（或文件结束）的各行，是这条输入的**期望输出**，按顺序逐行严格相等比较（包括空格），不允许多也不允许少。
- 两条输入相邻，表示前一条没有输出（例如 `#` 注释，约定补充 R2）。
- 文件为 UTF-8、LF 换行、以换行结尾；没有空行，也没有行尾空格。本阶段没有命令会输出空行；以后如果出现，需要扩展本格式。
- 不包含 banner 和提示符：它们由 `cli/Repl` 打印，不属于 `Editor` 的返回值；非 TTY 时也不打印提示符（R1）。

**文件系统**：运行器应注入内存版 `FileSystem`，预先放入 `fixtures/other.svg`，路径为 `other.svg`；会话中的 `save demo.svg`、`save flowchart.svg` 写入这个内存文件系统，不碰磁盘。
